# Examples

本目录包含 journaling 技能参考示例，帮助 agent 理解不同场景下的推荐做法。

| 子目录 | 内容 |
| `journal-standards/` | Journal 标准文件示例——INDEX.md（总览面板）与规则文件示例（分类/标签板块）。示例沿用旧版拆分形态（CLASSIFICATION/TAGS 独立文件），现行模型为规则文档（RULES.md）单入口，板块内容可参考 |
|--------|------|
| `classification-systems/` | 分类体系示例——各种个人笔记组织系统的方法、结构和适用场景 |

每个示例文件以摘要头开始，agent 可通过摘要判断是否需要完整阅读。
