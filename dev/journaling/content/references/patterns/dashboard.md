# Dashboard — 项目/领域级次级 INDEX 设计参考

> 这是项目级别的组织设计参考，不是现成模板。旨在提供设计启发——你的 Dashboard 应从实际使用中生长，不预设最终形态。

---

## 定位

Dashboard 即"二级 INDEX"：

```
INDEX : journal = Dashboard : project/domain
```

功能一致（状态概览 + 快速路由），但 INDEX 覆盖整个 journal，Dashboard 覆盖一个项目/领域。设计参考与 INDEX 一致——不重复定义，参见 `../design-index.md`。

## 是什么 / 不是什么

- **是**次级 INDEX：状态概览 + 快速路由，覆盖一个项目/领域
- **不是**分类目录索引——不枚举条目，只指引关键路径
- **不是**内容容器——不持有内容副本，条目仍按分类存放，通过链接提供指引
- **不是**初始化预设——从实际需求中生长出来

## 引导路径

若无引导路径则无法被感知——通常来自 INDEX 的一行路由，也可以是上级 Dashboard（支持多层）。

## 生命周期

- **创建**：维护阶段按需生长，放在项目的目录下
- **持续**：随项目更新状态与路由链接
- **归档**：项目结束，不再更新——变成历史参考文档
