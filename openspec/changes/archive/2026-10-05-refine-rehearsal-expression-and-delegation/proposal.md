# Proposal

## Why

rehearsal 技能的表述存在系统性问题。关键边界句「推演止于评估」易被误读为对推演行为的流程约束（「做到 P5 就停手」），而其实际含义是技能的指导范围声明——指导推演步骤本身，不定义报告解读与修改决策；委派推演产出的报告可能包含误判，技能缺少接收侧的论述；「不正确的暗示」只覆盖写了什么，缺席与详略语气作为暗示来源未覆盖；场景路由隐含材料是单一载体类型的假设。更广地看，技能正文中自创复合术语与悬浮表述累积（「首次接触-理解-决策链路」式压缩串、未铺垫即使用的概念词），整体可读性不足，未参与编写的读者理解成本高。

同时，委派机制存在第三种形态的真实需求：现有委派将材料整体交接给子代理，子代理读到后段时已被全局视野污染，「首次接触」不成立，P3 的期待探针退化为已知答案的核对。需要一种把阅读过程按段流水交接的委派方式（代理对读），使线性、动态的阅读体验由通信结构保证而非依赖推演者自觉。

## What Changes

本变更包含三块，块 3 依赖块 1、2 落实后执行。

**块 1：新增代理对读（agent-paired-reading），委派推演三形态并列**

- 新增补充参考 `references/supplementary/agent-paired-reading.md`：分段流水交接的委派方法——主侧承担 P1 全部准备、按材料自然结构切分片段、逐段传递并收集反馈、P5 评估整理；子代理只被设定身份和当前片段，对每段产出理解状态反馈（复述、期待、困惑）；唯一不变量为「子代理对第 n 段的反馈先于收到第 n+1 段」。文档如实交代方法边界：切分边界本身携带信息（按自然结构切，不自创边界）、子代理看不到衔接带（前置必要上游文本并标注，或声明该路径推演不到）、适用面为线性消费的材料。
- guide「执行策略推荐」改造：通用方法（直接推演）为基座、始终完整可用；现有「委派并行推演」段（单推演者委派 + 批量执行的嵌套路由）改造为「委派推演」三形态并列——单推演者委派（材料整体交接）、批量委派（按场景交接）、代理对读（分段流水交接）。三形态本质相同（把模拟阅读外派给独立推理实例以隔离作者上下文），区别在于外派结构；各形态一段，写明外派什么、怎么外派、由此适用什么、代价是什么。选用条件口径统一为「有能力委派时可考虑选用」——能力是前提，选用是裁量，不由能力自动触发。
- SKILL.md 注册新文档（补充参考清单与目录树）。
- spec 新增 Requirement「代理对读」，与「委托路由」「批量委派」并列。
- 交叉引用同步：prompt-instruction 场景与 batch-execution 引用「通用论述『执行策略』中的委派并行推演」的措辞随伞名重定同步更新。

**块 2：表述更正**

- 「推演止于评估」改为范围声明式表述：技能的指导范围是推演本身，到推演结论的产出为止；报告解读、意见取舍、是否修改与如何修改是使用者当前任务的一部分，不由本技能定义。guide P5 开头段落与 spec Requirement「行为边界——推演止于评估」同步修改（Requirement 名称一并重定）。
- 「不正确的暗示」扩展：暗示的来源除结构、顺序、标题、措辞外，补充缺席（材料没提 X，读者推断 X 不需要、不存在、不被支持或不危险）与详略语气（例子的选择、详略对比、约束强弱的对照面）。核对标准不变：读者从缺席或表达方式做出的推断是否为作者意图，判定仍锚定读者身份检验。落点为 guide P3 留意之处条目与 spec「元语境渗漏术语群」第 (5) 条定义。
- 场景路由提示：载体类型判定可以推演范围的部分为单位——复合材料（如变更提案的多工件）按部分各自匹配场景；部分间衔接（指向、依赖、术语、承诺一致）按既有衔接带纪律照常推演。提示性扩展，不新增机制。
- 委派报告解读论述（guide 委派段）：子代理记录中的「理解」与「意见」性质不同——理解是模拟读者的真实状态，是数据；意见是子代理的判断，可能误判。驳回一条意见时核对其依据的理解是否可由材料文本加身份设定触发：可触发则意见虽驳回，该理解偏离本身仍是发现；仅源于子代理自身问题（带入外部上下文、未按身份阅读、臆造内容）的才整体排除。

**块 3：全面表述朴素化检查（依赖块 1、2 完成）**

- 逐文件检查 SKILL.md 与 references/ 全部内容，消解复杂的、难以理解的自创词汇：未经定义即使用的概念词、压缩成串的框架名、未铺垫的隐喻与比喻。
- 目标是技能表述朴素、准确：每个术语首次出现处可理解或已定义；读者不参与编写过程也能凭文字理解。
- 检查与修复以块 1、2 之后的文本为对象；发现的自创词按「定义后用、改用朴素表述、删除」三种方式处理，不保留悬空术语。
- spec 新增 Requirement「表述朴素性」，将上述目标立为可检验的术语表述约束。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `rehearsal`：行为边界表述重构为范围声明（Requirement 重命名与措辞修改）、「不正确的暗示」定义扩展（缺席与详略语气来源）、新增代理对读 Requirement、新增表述朴素性 Requirement、委派推演三形态结构对齐（批量委派 Requirement 措辞同步）。
