# 维护备忘录（Maintenance Memo）

> 通过一个独立的文档，在 journal 使用过程中随手记录延后执行的操作备忘。有效降低写入操作复杂度，减小笔记操作对主会话话题的注意力干扰。

## 核心方法

设置一个【维护备忘录】文件——特殊的笔记文件：

- 此文件不被 INDEX 感知，仅在笔记库规则之中进行规范
- 写入操作执行过程中，发现一时难以决断、或暂时不用操作的事，记录其中
- 备忘记录可以不是具体操作，但必须准确：一项（或多项）操作具体如何执行不用过多纠结
- 备忘录中的记录在被处理之后就删除
- 不建议设置多个【维护备忘录】文件

**注意**:在笔记库规则中应该强调：

- 被延后的操作不应该影响即时读取，不能胡乱延后必要操作
- 此文件必须在笔记库规则中可被感知

## 一种可能的做法

这是一种做法参考，不直接照搬，按笔记库自身情况调整。

规则文档中的约定：

```
## 维护备忘录

维护备忘录位于 memo.md，不登记到 INDEX。写入时发现的延后操作记入其中，
维护时统一处理。
```

备忘录内容：

```
- 经验目录 2026-06 条目密集，考虑细分
- 标签 imported 用法不一，检查统一
```

反例：

```
- 有些笔记需要整理
- 新条目的 INDEX 登记
```
