# agent-prompt-design

技能帮助 agent 设计、编写 Agent 系统提示词，并诊断既有提示词的指令问题，覆盖结构设计、内容编写、工具协议、安全加固与运营管理。

## 技能承接的范围

### 技能只产出方法论、模板与诊断

技能产出方法论、模板与诊断，不产出垂直领域的业务文案、代码实现、训练级指导（微调、RLHF）与非英语模型的本地化建议。agent 应当能够在请求越出这些边界时说明技能不覆盖。

### 技能区分系统提示词与一次性提示词

技能承接系统提示词的编写请求与既有 Agent 的指令问题诊断（冲突、工具过载、安全漏洞），不承接一次性普通提示词的编写。agent 应当能够按请求对象判断是否使用本技能。
