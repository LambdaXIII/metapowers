# web-entity-search

技能帮助 agent 快速查清一个具名实体的基本情况：按维度清单约束一次搜索的覆盖范围与停止时机，产出结构化但自然的回答，不做深度研究。

## 技能的边界

### 一次只处理单个具名实体

技能处理单个具名实体，覆盖该实体类型的必填维度（维度清单按实体类型定义在技能内容中），不做链式线索追踪、多实体对比或争议的深入分析。agent 应当能够在请求超出单实体范围时说明技能不覆盖。

### 只规定搜什么、搜多少、何时停、怎么呈现

技能只规定「搜什么、搜多少、何时停、怎么呈现」，不规定使用哪个搜索工具或如何提取网页内容。agent 应当能够自由选择工具。

### 边界用功能描述、不点名其他技能

技能表达与其他能力的界线时用功能描述，不点名其他技能。agent 应当能够在不引用别的技能的前提下说清界线。

## 检索判定

### 每个维度要有两个独立来源

一个维度要有 ≥ 2 个独立来源交叉一致；单一来源填入并标注未验证，两轮无果标「未查到公开信息」。技能不推测填充，也不在单一维度上深追。agent 应当能够交出每条结论的来源状态。

### 必填维度处理完即停

必填维度处理完即停；置信回检只抽查 2-3 个关键维度，不全量回检，也不因发现矛盾重开搜索链路。agent 应当能够在第一次覆盖完成后结束检索。

### 争议实体标注分歧后停止

高度争议实体标注「关于 X 存在不同说法」并列明分歧点后停止，不评价任何一方或给倾向性结论。agent 应当能够交出分歧而不选边。

## 交付形态

### 交付为自然语言段落

维度模板是搜索期的内部清单，交付为自然语言段落，不以表单、字段列表或检查表形态出现。agent 应当能够让回答读起来像一段话。

## 何时加载技能

### 触发面是具名实体的快速问法

技能的触发面是中英两类的具名实体问法；判定以搜索结果的实体特征为准，不依赖句式穷举，也不由话题型调查（多来源交叉比对）触发。agent 应当能够按实体特征而非句式决定是否加载。
