# skill-master 元语境渗漏与措辞诊断摸底

## 背景与目的

本报告是对 `dev/skill-master/content/` 全部内容文件（入口 1 + 参考文档 17 + 模板 3，`content/scripts/` 为空目录不计）的**措辞混乱与元语境渗漏**系统性诊断，作为后续修复工作的参考。

由来：独立审查（2026-09-08 会话）发现该技能按自身四标准（Useful/Complete/Accurate/Clear）检验时 Clear 失分——密度过载、未定义术语、若干语病。进一步讨论确认：这些问题不在知识层（机制、判据、四册闭环真实有效），而在表述层，且根因指向**元语境渗漏**——写作对话的语境（词汇、句式、论证、语气）进入了成品文字。本报告对全包做逐文件摸底，归纳错误模式，形成可逐条消费的修复清单。

**范围限定**：只判表述，不判知识对错。同类但不同根因的缺陷（同一判据两处各写一遍的「转发」类重复：`skill-design.md:43`/`skill-review.md:36`、`skill-modify.md:9`/`script-design.md:44-45`、`skill-design.md:53`/`skill-quick-test.md:72`、报告格式双份 `execution-light.md:66-79`/`scenario-card.md:18-43`）已在独立审查中记录，属化石类，本报告仅在附录汇总，不展开。

## 诊断框架

### 什么是元语境渗漏

信息传递模型：作者的意思 → 文字材料 → 读者解读。写与读是两个过程，各自携带语境：

- **元语境**：写过程携带的语境——写作要求、设计意图、写作态度、对文本的自我定位、写作过程状态。
- **文字语境**：读过程面对的语境——读者使用文字完成任务所需的信息。

**元语境渗漏 = 写过程的语境进入了文字载体。**

判定标准是**语境归属**（这条文字服务于写过程还是读过程），不是形式标准——「作者现身」（第二人称、自称「本册」）只是渗漏的常见形态，既非充分也非必要。识别三步：**层定位 → 建立读者任务 → 功能检验**（这条文字对读者的判断任务有功能吗？有功能但依赖写作语境才成立 = 渗漏，改写；无功能 = 残留，删）。

渗漏五层（从可见到不可见）：

1. **词汇层**：内部代号、简称、口头量词（最可见，危害最小）。
2. **句式层**：宣布式句子、对着持有论证的对话者坍缩的句法、拿作者出处当理由。
3. **论证层**：决策由设计对话或作者经历辩护，而非读者可得的机制或实践。
4. **语气层**：训诫腔、辩护腔——文本在跟不在场的对话者争吵。
5. **选择层**：话题、重点、例证由作者传记决定，而非读者失败模式分析。

严重度两维：**误解读后果**（完全无法解读的困惑 ＜ 可被误读为规则的误导 ＜ 误导且改变行为）× **穿透层数**。推论：**误导性渗漏比困惑性渗漏更危险**——它不暴露，读者无从察觉自己读错了。

修复三分法（穷尽）：**删**（对任何读者任务都无功能）／**归位**（对另一载体的读者有功能，如设计意图归设计侧文档）／**转化**（对当前读者有功能但形态是写过程的——保留功能，改写为读者语境的形态）。

### 本技能的判定基准（防误伤）

以下情形**不算**渗漏，扫描中不报：

- **任务词汇**：skill-master 的读者任务是「帮助用户把实践做成技能」，任务本身包含与用户讨论、请用户确认——「讨论」「用户确认」「交付」是任务词汇，不是写作语境残留。
- **已声明的范围边界**：「本册不管什么」是确定内容（`writing-craft.md:35` 自己裁定过）。
- **就地定义后的自造词**：「涟漪式节奏」「条件依赖者」「病灶七类」等均定义后使用，是合法的引导词。
- **有功能的告诫**：作者式提醒若服务读者操作（如「先写支撑文件再写入口」），功能检验通过。
- **模板 = 零写作交接层**：模板被拷贝使用、中间读者不重写，其中的渗漏只能靠写时预防；已渗入的按最高优先级记录（穿透层数最深）。

另注意**演化渗漏**：结构升级后原声明变假——本包刚经历 v0 判废重建与 quick-test 并入，是演化渗漏的高发土壤。

### 错误模式编码

**W 系（措辞混乱）**——可读性/语法/术语问题，不依赖语境归属判定：

| 码 | 模式 | 判据 |
|---|---|---|
| W1 | 坍缩句 | 语法残缺或压缩至冷读无法解析（如「值不值押上到达率」） |
| W2 | 跨语言断桥 | 英文入口与中文正文词汇体系未桥接，同一概念双名无对照 |
| W3 | 术语未定义 | 概念词首次使用无就地定义，冷读者无法确定所指 |
| W4 | 超载复句 | 单句多层嵌套，需多次回读（只记最重者，不记正常密度） |
| W5 | 歧义指代 | 指代对象不明，或同一术语在一处有两个所指 |

**L 系（元语境渗漏）**——按语境归属判定：

| 码 | 层 | 模式 |
|---|---|---|
| L1 | 词汇 | 写作对话的代号/量词/简称进入正文且未定义（「册」「工作论述」） |
| L2 | 句式 | 对话者持有论证时才成立的句法坍缩；宣布式句子 |
| L3 | 论证 | 声称的依据在写作对话或作者经历中，读者不可核验（匿名个案引证、无出处统计） |
| L4 | 语气 | 对不在场对话者说话：反驳句、训诫腔、辩护腔 |
| L5 | 环境 | 作者环境的事实（白名单、目录、配套文档、外部技能名）写进通用方法文本 |
| L6 | 选择 | 话题/例证由作者经历而非读者失败模式决定（与 L3 常伴生，按主层归类） |

严重度：**高** = 误导性渗漏（改变行为且不暴露）或阻断理解；**中** = 困惑性但可恢复；**低** = 残留摩擦。

W 与 L 交叉时按主层归类：源自对话内部代号的归 L1，中性自造词缺定义的归 W3。

### 扫描方法

逐文件通读（内容为本会话完整读取，引文均带行号），每文件先给结论（有/无缺陷），缺陷逐条列表。模式编码在扫描中随发现细化——L5、L6、W5 即扫描中新增，非框架预设。

### 分布观察

渗漏与**文件形态强相关**：L 系 20 条中 17 条集中在纯论述形态的册（design、review、disclosure、structure、skill-md-writing、script-design）；quick-test 八册与模板（逐字模板、数字阈值、表格硬约束形态）几乎干净，11 个完全干净的文件全部是执行/模板形态。这印证了 journal 写作元问题篇的判断——没有结构约束句式的论述是对话语体的温床，也提示修复后同类风险仍将随论述册的演化和再次并入而回归，检测链（外部推演复核）需要常态化。

严重度分布（高 0）说明：本次摸底**未发现确凿的「改变行为且不暴露」级渗漏**——最接近的两处（S2 环境假定、载体词）都有天然暴露点（读者找不到文档会停顿、检查项完不成会犹豫）。渗漏以困惑性为主，这与 v0 判废时的「误导性极强」相比是质的改善，但困惑性渗漏的累计成本正是审查发现的 Clear 失分。
