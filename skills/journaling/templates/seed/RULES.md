# Journal Rules

> 本文件定义本 journal 的规则：INDEX 结构、分类、笔记元数据字段、写作约定等。
> 本文件规则非技能强制、可调整——各板块可按 journal 实际需求增删改。

## INDEX 结构

INDEX.md 是笔记库的唯一入口，开头部分应保留此重要提示：

```Markdown
**Journal中的内容都是过去的你留下的重要信息，应当以本INDEX为线索，主动读取相关内容**
```

INDEX.md 包含这些板块：

- 协议声明节：技能管理标注 + 读写加载标注
- 条目索引节：每条笔记登记一行——名称 + 一句话摘要 + 链接。条目写入后登记，状态变化时更新

## 分类

> 目录规则：什么内容放在哪里。
> 不存在时按需新建即可。

| 目录 | 放什么 | 不放什么 | 一句话判断 |
|------|--------|---------|-----------|
| `inbox/` | 缓冲：不确定归属的内容，先放这里 | 已明确分类的内容 | 知道放哪？→ 直接放目标目录。不确定？→ inbox |
| `experience/` | 经验：个人实践产出的教训、决策、方法论 | 外部研究、进行中的任务 | 这来自我的实践吗？→ experience。来自外部？→ knowledge |
| `knowledge/` | 知识：外部来源的研究、文献笔记、参考资料 | 个人经验、活跃任务 | 这是我的原创经验吗？→ experience。来自外部？→ knowledge |
| `active_works/` | 工作动态：当前任务进度、备忘、进行中事项 | 已完成的经验、归档知识 | 这需要后续跟进吗？→ active_works。已完成？→ experience |

## 条目笔记命名

日期+标题/主题：`YYYY-MM-DD-主题.md` - 其中日期为笔记的创建日期。

## 笔记元数据字段

| 字段 | 用途 |
|------|------|
| `title` | 条目标题 |
| `summary` | 摘要：定义本条目的范围边界 |
| `tags` | 标签：简短词汇，从内容、用途等维度描述条目 |
| `last_update` | 最后更新日期：跟踪时效 |
