## 1.0.0
- 新建技能 skill-exposition（技能阐述）：将一个技能（或其中指定的某些方面、或多个技能）转化为人类可读的说明文，让人类可以通过阅读材料学会这项技能
- 边界模型：展开指导（梳理、阐述陷阱、组织知识）与效果提及（行文、质量检查、工程执行）分离
- 结构：SKILL.md 入口化 → 通用论述（exposition-guide.md，自包含）→ references/ 三目录按需加载（extraction/ 5 + structure/ 8 + general/ 4）
- 输入范围：完整技能包 / 技能部分方面 / 多技能（含跨技能方面），不假定完整技能；方面跨文件分布时先定位分布再提取
- 输出形态：单篇说明文（逻辑整体，多技能批量每技能一篇、跨技能方面单篇整合）；语言与学习者一致、术语首次出现附源语言原文
- 产物自包含：产物是读者唯一依据，绝不反向链接技能内部文件；源混排语言时术语保留原文、行文统一为学习者语言；制式性内容原样保留、叙述性示例转述
- 源一致性裁决表（6 检查 + 7 裁决策略）
- 推断标注纪律（`[推断: 依据]` / `[未推断: 原因]`）
- 陷阱四类框架（内容失真 / 视角漂移 / 推断未标注 / 语体残留认知面）
- 行为边界：只读源文件、不修改、不执行、不测试、不评价
