# Domain Docs

工程技能探索代码库时应如何消费本仓库的领域文档。

## 探索前阅读

- 目标技能的 `dev/<skill>/SKILL-DESIGN.md` —— 设计意图、设计目标、关键架构决策（含理由）、措辞风格约定、维护注意事项。本仓库的领域知识（术语选择与决策理由）在这里
- `dev/<skill>/research/CONTEXT.md` 是**开发期会话账本**（domain-modeling 过程的工作记录，定案后并入 SKILL-DESIGN）——不承诺存在、不承诺完整，不作为领域文档入口
- 仓库根无 `CONTEXT.md` / `CONTEXT-MAP.md` / `docs/adr/` —— 本仓库领域文档在技能层

以上文件不存在则**静默继续**，不提示缺失、不预先创建。

## 术语使用

命名领域概念（重构提案、假设、测试名等）时，用 SKILL-DESIGN 中确立的术语（措辞风格约定），不漂移到回避的同义词。

## 标注 ADR 冲突

本仓库暂无 ADR；将来若引入（跨技能级决策），输出与其矛盾时须显式标注而非静默覆盖。
