# Classification Systems

> 内容归类模式集合——「内容按什么维度归类」这一组织层面的构思框架。归类方式需要设计或调整时，从这里寻找匹配的模式。

## 核心方法

先明确归类问题——内容按什么维度组织——再从以下抓手找到匹配的模式，读对应文件全文。每个文件以摘要开头，先读摘要判断是否需要全文。

### PARA（para.md）

按可行动性归类：内容现在需要行动？未来可能有用？还是已完成？四个容器：Project / Area / Resource / Archive。

### Zettelkasten（zettelkasten.md）

按概念归类：一个笔记 = 一个概念，原子笔记 + 链接网络。

### Johnny Decimal（johnny-decimal.md）

固定编号空间：10×10 槽位，编号即位置，跨工具一致。

### MOC / LYT（moc-lyt.md）

导航优先：MOC 笔记作为分类代理，索引笔记替代移动文件。

### Evergreen Notes（evergreen.md）

按演化程度归类：笔记随时间精炼和链接，从种子笔记生长出成熟条目。

### GTD Contexts（gtd-contexts.md）

按可用手段归类：回答的不是"这是什么"，而是"我能在这里做什么"。工具 / 地点 / 精力状态。

模式在适用边界内成立；边界外套用形态是模式误用。
