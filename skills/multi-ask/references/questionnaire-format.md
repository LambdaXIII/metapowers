# 问卷格式

问卷是一份普通 markdown：章节、段落、列表、引用都照常写，问题块嵌在论述之间。

渲染有边界：表格按等宽预格式化文本显示，嵌套列表被拍平，有序列表的起始序号不保留，`mermaid` 图需要浏览器能访问 CDN。不要靠排版承载必须逐项对照的信息。

## 问题块

围栏语言就是题型：`single-choice`（单选）、`multi-choice`（多选）、`yes-or-no`（判断）。`multiple-choice` 是 `multi-choice` 的别名。

只有这三种围栏是问题块，其余围栏按正文代码块渲染；围栏名写错（如 `multi_choice`）也按正文处理，校验会提示。

块内只有两层：

1. 块内第一行（空行不计）`<块 id> 题面`，题面可续写到第一个选项行为止。
2. 选项行 `- [ ] <选项 id> 选项文本`，顶格写、一行一个。方括号内写 `x`（`- [x] <选项 id> 文本`）标记推荐。

选项行之后的普通文字并入上一条内容（还没出现选项时并入题面，否则并入上一条选项），块内不另起段落；要补论述，写到块外。题面与选项文本都可以续写，续写行以空格连接。

id 写在尖括号内，非空、不含空格；块 id 全卷唯一，选项 id 只在块内唯一。id 只供脚本配对答卷，页面上不显示。

````markdown
```single-choice
<scope> 第一批收窄到核心命令，其余功能留到第二批。
- [ ] <narrow> 收窄：本月能上线，用户暂时看不到导出与批处理。
- [x] <wide> 一起做：功能完整，上线推到下个季度。
```
````

复制上面的样例做问卷时，去掉外层四个反引号。

推荐标记只是建议：不预勾选、不进答卷、不出现在拼装结果里，可以标多个，也可以不标。

## 题型

| 围栏语言 | 页面控件 | 答卷记录 |
|---|---|---|
| `single-choice` | 单选 | 选项 id 数组，0 或 1 个 |
| `multi-choice` | 复选 | 选项 id 数组，任意多个 |
| `yes-or-no` | 单选 | `["yes"]` 或 `["no"]`；未答为空数组 |
| 零选项的 `single-choice` / `multi-choice` | 无控件，只有自由输入 | 空数组 |

任何一题都可以整题跳过；跳过或未答在答卷里是空数组加空串。

`single-choice` 与 `multi-choice` 只写一个选项不通过校验：候选只剩一个，说明答案已经在提问这一侧定型。

`yes-or-no` 不写选项时，页面给出「同意 / 驳回」。写了选项时只接受 `<yes>` 与 `<no>` 两个 id，文本替换默认标签；`<yes>` 的文本必须表达命题成立的那一侧——写反了，用户点的和你读到的会颠倒。两侧都给：只给一个，另一侧在页面上就不存在。

## 自由输入与总评

每题恒定带一个自由输入框，卷末恒定带一个总评框，都不在问卷里声明。不选选项、只写自由输入，也是合法作答。
