# skill-exposition

技能把 agent 技能转化为人类可读的教学材料，让没有技能目录的人读完之后能够理解并照着做。转化是形式操作：只重组组织形式，不改变源技能的实质内容。

## 技能的边界

### 技能只读不执行

技能只读技能源文件，不执行、不测试、不评价被阐述的技能；产物止于教学材料，学习者学会后的应用与再创造不属于技能范围。agent 应当能够只凭源文件完成阐述。

## 输入怎么被取全

### 一个方面跨多个源文件时先定位全部位置

一个方面跨多个源文件分布时，先在源中定位范围内内容的全部位置再提取，不只取 SKILL.md 正文。agent 应当能够交出覆盖完整的材料。

## 产物长什么样

### 单技能或单方面产出单篇说明文

单技能或单方面产出单篇说明文，多技能各产一篇，跨技能方面产单篇整合并逐段标注来源技能；超长可拆为章节文件，不拆成多目录文档包。agent 应当能够在产物规模变大时仍保持单篇形态。

### 产物语言与学习者一致

产物语言与学习者一致：源内容混排语言时，术语保留原文并附学习者语言的翻译，行文统一为学习者语言。agent 应当能够交出通篇一种语言的材料。

## 忠实性

### 产物不歪曲、不省略、不劣化

产物不歪曲、不省略、不劣化，也不反向链接技能内部文件，理解所需前提全在产物内。制式性内容按价值所在呈现：格式型（模板、清单、格式规范）原样保留，含义型（叙述性示例、场景演示）转述为说明文语言。agent 应当能够让读者不必打开源技能。

## 技能自身内容的展开范围

### 只展开三块认知内容

技能只展开梳理（提取与源一致性裁决）、阐述陷阱、组织知识三块；界外内容（行文、质量检查、工程执行）只以「确保……」效果句声明效果，不展开做法，也不引入阶段、门禁、管道等流程工程。references/ 可承载界外内容的启发形态，按需加载不构成展开指导。agent 应当能够分清哪些是技能教的做法、哪些只是效果要求。

### 阐述陷阱只有一个事实源

阐述陷阱统一为四类框架（内容失真、视角漂移、推断未标注、语体残留），同一纪律不在多处重复声明。agent 应当能够在需要陷阱清单时只查一处。
