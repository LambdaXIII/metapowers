# 多技能场景专项

> 输入为**多个技能**或**跨技能方面**时加载。多技能场景在通用论述方法之外需要五类纪律：范围界定、批量纪律、跨技能一致性、归属纪律、组合组织。单技能场景不适用本文。

## 1. 范围界定：技能清单 + 每个技能涉及的方面

动笔前先建立范围表，避免两个错误：漏技能、漏方面。

| 技能（含 SKILL.md 的目录） | 本次涉及的方面 | 方面在源中的位置 |
|----------------------------|----------------|------------------|
| 技能 A | 完整 | SKILL.md + references/ + CHANGELOG.md |
| 技能 B | 委派机制 | SKILL.md 流程章节 + references/workflow.md |
| 技能 C | 委派机制（跨技能方面） | SKILL.md + references/… |

- **跨技能方面**：明确该方面在每个技能中的位置——一个方面可能跨多个源文件分布（通用论述 2.2），跨技能时每个技能都要单独定位
- 范围由用户指定：可能是"多个技能各自完整"（输出每技能一篇），也可能是"跨技能的某个方面"（输出单篇整合）——先确定属于哪种，再决定后续纪律的适用对象（通用论述 2.1）

## 2. 批量纪律（各自完整输出时）

输入为多个技能、各自完整输出时，交付物是**每技能一篇说明文**（通用论述 §1 交付物形态）。

- **逐个独立完成**：每篇的梳理、组织、行文独立进行，一篇的内容不"借"另一篇
- **范围互不污染**：技能 A 的内容不进技能 B 的篇目；跨技能共用的表述（如两个技能都用"委派"一词）各自按各自源的语义呈现，不因为"两篇都写"就强行统一措辞
- **每篇单独对照忠实性要求**：不因"反正有另一篇"而省略某篇中的细节；忠实性是逐篇验收的
- **每篇单独对照通用论述**：陷阱自查、推断纪律、语言要求逐篇应用

## 3. 跨技能一致性：矛盾并列呈现，不擅自裁决

技能 A 与技能 B 对同类内容说法矛盾时（如对"委派"的触发条件规定不同）：

- **并列呈现 + 标注归属**：写明"技能 A 规定……；技能 B 规定……"，逐条注明出处
- **不擅自裁决谁对**：通用论述 2.4 的裁决纪律针对同一技能内的源文件矛盾（存在权威层级可依）；跨技能矛盾没有权威来源——两个技能各自是各自领域的权威，A 与 B 说法不同是事实，不是错误
- **不调和成折中说法**："A 与 B 大致相同，略有差异"式的折中 = 对双方都不忠实
- 差异若可解释（如版本不同、适用场景不同），解释本身按推断纪律标注

## 4. 归属纪律：整合阐述中每段标注来源技能

跨技能方面整合成单篇说明文时，**每段内容标注来源技能**（通用论述 §1：单篇整合说明文，每段标注来源技能）。

- **张冠李戴 = 新的失真形式**：把技能 A 的做法说成技能 B 的，是内容失真在跨技能场景的具体形态——读者学会的"技能 B"实际是 A 的行为
- **标注方式**：段落标注技能名，如"（来源：技能 A）"；同一技能连续多段时无需每句重复，但**切换技能时必须标注**
- **对比性内容**：逐条并列并各自标注，如"技能 A 用 X（来源：技能 A）；技能 B 用 Y（来源：技能 B）"
- **自查**：读者能指出任意一段出自哪个技能吗？标注缺失或含糊 = 归属失败

## 5. 组合组织：逐技能分节 vs 按主题整合

单篇整合说明文内部的两种组织方式：

| 方式 | 做法 | 适用情况 |
|------|------|----------|
| 逐技能分节 | 每个技能一个章节，章节内部再按方面组织 | 方面重叠少；每个技能的自洽性强；读者通常一次只看一个技能 |
| 按主题整合 | 一个主题章节容纳所有技能对该主题的做法 | 方面重叠多（如多个技能的委派机制）；读者需要对比；跨技能方面本身就是主题 |

- 两种方式都是"单篇整合说明文"内的组织选择，不改变交付物形态
- **可混合**：按主题分章，主题内部再按技能分节；对比性内容用并列标注
- **选择依据是学习路径**：按主题整合时，读者能否从每个技能的角度重建完整图像（防碎片化）？逐技能分节时，跨技能对比是否仍然可达（防遗漏对比）？组织方式服从"学会"目的（可读性硬约束），与归属纪律正交——无论哪种方式，每段内容都标注来源技能
