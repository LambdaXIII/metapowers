# Design

## Context

rehearsal 技能为三层结构（SKILL.md 入口 + 通用论述 guide + scenarios/supplementary 参考），行为契约在 `openspec/specs/rehearsal/spec.md`。委派机制现状：SKILL.md「委托路由」承担整体委托（路由决策，不在本变更范围）；guide 执行策略「委派并行推演」段内嵌两个形态的路由——单推演者委派（方法在 prompt-instruction 场景「委派推演」节）与批量委派（场景 ≥ 5，方法在 supplementary/batch-execution.md）；spec 有「委托路由」「批量委派」两个对应 Requirement。变更动机见 proposal.md 的 Why。

## Goals / Non-Goals

**Goals:**

- 代理对读以独立补充参考落地，guide 委派论述改造为三形态并列、入口集中
- 行为边界从「推演止于评估」的流程约束式表述重构为范围声明式表述
- 「不正确的暗示」补齐缺席与详略、措辞强度两类暗示来源
- 复合材料的部分为单位路由提示、委派报告解读论述
- 全量表述朴素化检查与修复

**Non-Goals:**

- 不改推演方法骨架（P1–P5 步骤本体不动）
- 不改 SKILL.md「委托路由」（整体委托是进技能前的路由决策，非执行策略）
- 不新增场景文档
- 不动 spec 的「三层文件结构」「提示性框架边界」等既有契约；「批量委派」Requirement 不受本变更影响

## Decisions

**D1 代理对读放 supplementary，命名 agent-paired-reading**：方法是跨载体的（不绑定任何单一场景），与 batch-execution 同类；三层文件结构契约下 supplementary 是跨场景小块知识的归属。

**D2 guide 委派论述改造为三形态并列**：现有段是「单推演者委派 + 批量执行」的嵌套路由，伞名「委派并行推演」中的「并行」无法概括三形态（单委派与对读都不天然并行），伞名重定为「委派推演」。三形态的区分维度就是委派结构本身（整体交接 / 逐场景交接 / 分段传递），不另造分类轴——各形态一段，写明委派什么、怎么委派、由此适用什么、代价是什么。选用条件口径统一为「有能力委派时可考虑选用」：能力是前提，选用是裁量，不由能力自动触发——与「提示性框架」定位一致。

**D3 反馈时序约束是代理对读唯一硬性点**：子代理对第 n 段的反馈先于收到第 n+1 段。设计理由：整体交接下，子代理读到后段时已被全局视野污染，读者预期与后文的核对失效；分段传递把线性阅读从推演者与子代理的自觉（guide P3 的渐进式阅读纪律）升级为通信结构的保证。这一理由同时导出适用条件——篇幅长、前后依赖强的材料，预期要跨段核对才有价值——以及代价（通信轮数 = 片段数）。理由本身不进技能正文，正文只写方法与适用判断依据。

**D4 「行为边界——推演止于评估」改名 + 改写用 REMOVED(Reason/Migration) + ADDED 组合**：RENAMED + 新题名 MODIFIED 的组合能通过 validate 但 archive 预检拒收（MODIFIED 头按主规格现行名匹配，改名不在匹配前生效）；REMOVED+ADDED 是已实测的兼容通路。原两个场景（修改决策不越界、偏离如实记录）与轻量模拟定位声明语义保留。

**D5 语境纪律（块 1、2 写入约束）**：讨论与工件的表述是设计者之间的沟通；技能正文以运行时读者（未参与对话的 agent）为对象自足撰写——讨论措辞与 spec 措辞不直接搬进技能正文；设计理由只落本文件与变更记录，不进技能正文（设计内容分离）。

**D6 朴素性检查量具先行**：spec「表述朴素性」的三条场景（术语先定义、判断不依赖比喻、框架要素展开）即检查量具；逐文件检查先产出自创词与悬浮表述清单，逐条按「定义后用 / 朴素改写 / 删除」三选一处理；检查对象是块 1、2 完成后的文本。

## Risks / Trade-offs

- 代理对读的通信轮数 = 片段数，成本高于批量执行的单轮多代理：由适用条件限定（长且前后依赖强的材料），方法文档明确交代代价，不做万能宣称。
- 朴素性判定有主观空间：以 spec 场景为量具约束判定，全部文件同批检查避免口径漂移。
- guide 委派段重写牵动 prompt-instruction 场景与 batch-execution 的交叉引用，漏改产生悬空引用：任务清单单列逐点核对。

## Open Questions

无。三形态并列与伞名重定、命名、条件口径、反馈时序约束、方法边界交代均已与用户裁定。
