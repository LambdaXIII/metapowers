# skill-exposition 规格

本域约束「把 agent 技能转化为人类可读教学材料」这一转化：产物形态、内容保真，以及技能自身内容可以展开到哪里。转化是形式操作——只重组组织形式，不改变源技能的实质内容。

## 边界

- **只读不执行**：本技能只读技能源文件，不执行、不测试、不评价被阐述的技能；产物止于教学材料，学习者学会后的应用与再创造不属本域。反例：「先跑一遍流程再写」。

## 输入

- **全范围定位**：一个方面跨多个源文件分布时，应当先在源中定位范围内内容的全部位置再提取，不能只取 SKILL.md 正文。反例：「只读 SKILL.md」。

## 输出

- **篇章粒度**：单技能或单方面产出单篇说明文，多技能各产一篇，跨技能方面产单篇整合并逐段标注来源技能；超长可拆为章节文件，但不能拆成多目录文档包。
- **语言对齐学习者**：产物语言应当与学习者一致：源内容混排语言时术语保留原文并附学习者语言翻译，行文统一为学习者语言。

## 硬性约束

- **忠实自包含**：产物应当不歪曲、不省略、不劣化，不能反向链接技能内部文件，理解所需前提全在产物内；制式性内容按价值所在呈现，格式型（模板、清单、格式规范）原样保留，含义型（叙述性示例、场景演示）转述为说明文语言。反例：「详见 SKILL.md 第 3 节」。

## 内容形态

- **只展开三块认知内容**：梳理（提取与源一致性裁决）、阐述陷阱、组织知识；界外内容（行文、质量检查、工程执行）只能以「确保……」效果句声明效果，不能展开做法，也不能引入阶段、门禁、管道等流程工程。references/ 可承载界外内容的启发形态，按需加载不构成展开指导。
- **陷阱单一事实源**：阐述陷阱统一为四类框架（内容失真、视角漂移、推断未标注、语体残留），同一纪律不能在多处重复声明。
