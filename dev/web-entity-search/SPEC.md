# web-entity-search 规格

本域规定单个具名实体的快速检索行为：以维度清单约束一次搜索的覆盖范围与停止时机，产出结构化但自然的回答，不做深度研究。

## 边界

- **单实体快搜**：应当处理单个具名实体、覆盖该实体类型的必填维度（维度清单按实体类型定义在技能内容中），但不能做链式线索追踪、多实体对比或争议的深入分析。
- **范围收窄**：只规定「搜什么、搜多少、何时停、怎么呈现」，不能规定使用哪个搜索工具或如何提取网页内容。
- **边界表述**：表达与其他能力的界线时应当用功能描述，但不能点名其他技能。

## 硬性约束

- **来源标准**：一个维度应当有 ≥ 2 个独立来源交叉一致；单一来源应填入并标注未验证，两轮无果应标「未查到公开信息」。不得推测填充，也不得在单一维度上深追。
- **停止纪律**：必填维度处理完即停；置信回检只抽查 2-3 个关键维度，不能全量回检，也不能因发现矛盾重开搜索链路。
- **争议即停**：高度争议实体应当标注「关于 X 存在不同说法」并列明分歧点后停止，但不能评价任何一方或给出倾向性结论。

## 内容形态

- **自然段落交付**：维度模板是搜索期的内部清单，交付应当为自然语言段落，不能以表单、字段列表或检查表形态出现。

## 触发

- **实体问法**：触发面应当是中英两类的具名实体问法；判定以搜索结果的实体特征为准，不能依赖句式穷举，也不能由话题型调查（多来源交叉比对）触发。
