# 写模板

读者材料齐备却拼不出成品时，缺的是装材料的框架。模板提供这个框架：同类产物的章节、字段、顺序每次一致，差异只在填入的内容。

与工作流的分野看**填充过程需不需要判断**：

- 填充是「顺着填」——每一格填什么不需要决策，顺序即流程 → 模板。模板结构编码了操作顺序，填写指引就是操作指令。
- 填充需要显式判断、分支或回环 → 装不进模板，归[工作流册](workflow-writing.md)（缺动作序列）或[论述册](essay-writing.md)（缺判断依据）。

模板教结构不教内容：结构是模板的承诺，内容随任务变化。**追求填充内容也一致是设计者的幻觉**——内容每次都一样，说明那部分根本不该是可变位，该写进骨架。

## 从真实范例来

- 事实来源是实际产出的范例集合。拆解是把多个真实成品摆在一起比对，找共有形状——反复出现的章节、字段、顺序就是骨架；成品之间不同的地方留给占位符。
- 不从空白发明，也不参照格式说明再造。真实范例里藏着真实约束：形状长成这样是因为它服务过真实任务。凭空发明的形状第一次真实使用就露馅——它没被任何约束检验过。
- 骨架要对「这一类」任务成立，不是对某一次。只有一份范例时先不建模板：一份范例无法区分「反复出现的形状」与「这次碰巧的样子」，那正是化石的来源（见下）。
- 同一起点要求与工作流一致：先有被走通的产出，才有模板。模板从实际成品拆出来，不是从空白设计出来。

## 骨架与可变位

- 固定骨架是每次都相同的章节、字段与顺序；**骨架排序本身是信息**——按填充者的自然顺序排，填到哪一格就知道下一格该想什么。顺序乱了，填充者要在文档里来回跳。
- 可变位是占位符，作用是填空，不是自由发挥区。占位符用读者已熟悉、承载共识含义的词命名；自造抽象名（`<section-2>`、`<content-block>`）让读者无从判断该填什么。
- 可变位配**填写说明**，不能只用示例了事。说明交代四件事：每格填什么、材料从哪来、有什么约束、填到什么程度算完。示例展示的是一次填充的形状，读者会照着抄——抄来的形状在下一个案例上往往是错的。示例若保留，标成「样例」，不冒充模板本身。
- 层级控制在三层以内。更深的嵌套让填充者在缩进里迷路，也说明这一块其实该拆成独立模板或独立章节。
- 同类变体用**条件化字段**吸收（该字段只在条件成立时填），不另立新模板。每分叉一个模板，填充者多一次选型、维护者多一份同步，而分叉出的两份会在下一次修订时开始漂移。

## 试填验证

- 骨架成型后必须试填：拿**另一个**真实案例沿模板填一遍。拆解时用的范例不能拿来试填——骨架就是从它身上拆的，填它当然填得进。
- 试填检查四件事：每个占位符知道填什么、知道从哪取材料、知道填到什么程度算完、顺序走得通。任何一件卡住，是骨架错，**修骨架不修案例**——把案例改得适应模板，等于让真实任务迁就一次设计。
- 换个案例填不进去，通常暴露的是骨架里混进了个案属性：某个字段只有原案例才有。这种字段要么条件化，要么删。

## 判断依据不进模板

- 模板给填空位，判断依据成文在别处（论述形态），模板内只留指针。判断依据塞进模板，模板就长成方法论长文，填充者要在填格子的过程中读大段论述，节奏被切断。
- 判断指针同样守[编写手艺](writing-craft.md)的三要素：什么情况需要去查、去哪一节、查完拿到什么。

## 版本演进

- 新范例是修订输入。范例带来的差异先分辨性质：一次性变体不进模板，模板只编码反复出现的稳定形状；反复出现的结构变化才更新骨架与占位符。标准始终是「是否反复出现」。
- 模板变更是内容变更，走[修改工作](../skill-modify.md)。修订写入最新形状，**不并排保留新旧两套形状**——读者不知道按哪套走，结构信息就失效了。取舍与理由归设计侧记录，模板正文只承载当前生效的骨架。

## 化石防御

- 一次实务的成品格式不是方法论。对每一节问：**这是这类任务反复出现的稳定形状，还是我上一次交付物的残片？** 残片的典型是评估矩阵表、热力图、某次报告的分档表格——它们服务于那一次交付的呈现需求，不是这一类任务的形状。
- 个案规律同理：某一次里「几乎总是这样」可能是那个案例的性质，不是这一类任务的性质。可保留的是从实务提炼的实质洞察，不能保留的是个案外形。
- 无数据的定性比较（「耗时数小时 vs 显著缩短」）属于修辞不是依据，直接删。骨架来自多个真实范例的比对，化石只在拿一次产出当模板时发生。

## 边界

- 句子级手艺按[编写手艺](writing-craft.md)写，不在本册重复。
- 形态分工：框架内外需要判断依据的地方用[论述册](essay-writing.md)支撑，动作序列归[工作流册](workflow-writing.md)。模板正文保持可填充——它是一张表单，不该长成方法论长文。
