# Non-Read-Only Operations Reference

> 本文件承载改变 journal 状态的操作族——编写、收录、移动、删除等——共享的概述、原则与义务。
> 各操作只给最小指引；具体流程与语义由写入协议与 journal 规则承载，本参考不代述。

## 操作族

非只读操作指改变 journal 状态的操作：编写、收录、移动、删除，以及未来的同类操作（重命名、批量整理等）。厚操作（编写、收录）走写入协议的流程；薄操作（移动、删除）以本参考为去处，具体语义依 journal 规则。

## 共享原则

- **规则优先**：目录归属、标签、退场语义等判断依 journal 规则文档；本参考与各协议不预设 journal 侧语义。
- **轻量**：薄操作不引入协议级流程——入口可见、指引到位即可，操作本身由 journal 规则与判断承载。
- **关联一致**：笔记之间通过引用互相关联，改动文件名或位置会破坏指向旧位置的引用。

## 族义务：读取并遵守 journal 规则

任何非只读操作前必读 journal 规则文档——技能强制存在，即使为空；内容由 journal 自定（分类板块、标签板块、INDEX 结构板块、笔记元数据字段板块、写作需求板块等）。加载其中定义的规则并按之执行；为空或未定义相应板块时，用种子默认方案（目录/tag/元数据字段，见 ../templates/seed/）。

规则文档不存在属异常（强制义务：必须存在）——此时从 ../templates/seed/ 复制规则文档种子到 `<journal-root>` 补齐（入口文件名由机制固定；只补缺失文件，不触发初始化协议的其他步骤，避免连带覆盖已有 INDEX）。

本义务在此定义一次，各操作路径（写入协议、初始化、维护等）引用它，不逐字重复。

## 各操作最小指引

- **编写**（新建笔记、补充条目、更新 frontmatter）→ 流程见写入协议 [`protocal-write.md`](protocal-write.md)
- **收录**（将现存文档存入 journal）→ 拷贝文件到 journal 对应位置，再在其上修改调整（避免手工抄写）；frontmatter、summary、链接、分类等加工与写入流程一致
- **移动**（调整条目位置或文件名）→ 归属判断依 journal 规则（分类板块）；改动文件名或位置时，先搜索旧引用的全部出现位置，逐一更新并确认无残留
- **删除**（条目退场）→ 退场语义依 journal 规则的删除约定执行；本技能不设删除协议，不预设删除语义。 journal 规则未定义删除约定时的缺省回退：将条目移入临时保存目录（与维护协议的红线口径一致——不真正删除文件），并同步更新 INDEX 中该条目的登记行或链接。

## 与维护协议的层级

本参考是操作层的基础参考。维护执行期间，维护协议（[`protocal-maintenance.md`](protocal-maintenance.md)）的操作规范优先。
